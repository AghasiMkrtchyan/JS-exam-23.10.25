# Իմ ծախսերը — Android

Հայերեն, ամբողջությամբ օֆլայն անձնական ծախսերի հաշվառման հավելված։

- Գումարներ ՀՀ դրամով
- Օրական, շաբաթական և ամսական ամփոփումներ
- Կատեգորիաների գրաֆիկներ, ծախսերի պատմություն
- Գրառումների ավելացում, փոփոխում, ջնջում
- Ամսական բյուջե
- JSON պահուստային պատճեն և ներմուծում, CSV արտահանում
- Առանց գրանցման, գովազդի և ինտերնետի։ Տվյալները պահվում են հեռախոսի հավելվածի տվյալներում։

## Build

GitHub Actions → **Build Armenian Expenses APK** (branch `android-expenses-apk`), or:

```bash
gradle --no-daemon :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Android 8.0+ (`minSdk 26`). APK-ն debug ստորագրությամբ է՝ սարքում տեղադրելու և փորձարկելու համար, Play Store-ի համար release ստորագրություն չի պարունակում։ Հավելվածը ջնջելիս տվյալները կկորչեն՝ եթե նախապես պահուստային պատճեն չեք ստեղծել։
